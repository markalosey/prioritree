## §2 THE DONE SIGNAL — the class, the fields, the raise point

**[PROPOSED: the name `ExhaustedQueue`]** — from the act-statement "the queue is exhausted" (the walk's fall-through: no under-quorum pair remains, every pair at quorum k). The alternative AllPairsJudged refused: "judged" mis-names the keying — the census keys the QUORUM, not the judging. Mechanically an exception, semantically a terminal state: a sentinel priced out twice (it cannot carry evidence; the class of its OWN type means except-RefusedError never catches DONE).

**The N818 tension, priced both — [PROPOSED: the suffix-free name + a named per-file N818 ruling at pyproject citing this brief's §2 clause].** Price: one named ruling (the family's sanctioned surface — ARG001/PLR0913-17 the precedents). Reason: the Error suffix in this family marks the REFUSAL lineage — stamping it on the one non-error exception blurs exactly the distinction the class exists to carry ("distinguishable from error by TYPE"), and Python's own grammar for terminal signals is suffix-free (StopIteration — the loop's terminal, the closest kin). The alternative priced: ExhaustedQueueError — zero findings, zero new rulings — but the name lies (Error on a non-error), refused. The amendment-16 precedent distinguished: there the rename cured a name that lied; here the rename would create the lie.

**The fields' exact bytes [PROPOSED, drafted verbatim — the family grammar]:** expected = `f"all {len(queue)} scheduled pairs at quorum k={manifest.quorum}"`; found = `f"the queue is exhausted — the walk fell through with no under-quorum pair (every pair at quorum on the census's AS-IS counts)"`; next_action = `"call tally_rank(run_id) — the tally path (R12's DONE; a standing correction can still SAFE HALT it — the census-vs-weighted seam, named and carried)"`. The rendered message: `f"exhausted — expected: {expected} | found: {found} | next: {next_action}"` [the family's three-field render with the signal's own prefix — an uncaught traceback still names the state and the path; "refused —" would lie].

**The class hierarchy [PROPOSED: `ExhaustedQueue(Exception)` directly — a plain Exception subclass, zero deps].** Never a subclass of any RefusedError (the type distinction IS the hierarchy). Raised, never returned; the exact raise point: the loop's fall-through (§3) — the early return the hot path, the raise the terminal; no second pass.

## §4 THE SEAM'S HONESTY — the census-as-is consult vs the weighted gate

**The two keyings off the same quorum (R8), each at its ruled datum:** U5's consult — census.per_pair_counts AS-IS (+1 per record, no supersession filter — the unweighted audit view); U4's gate — the WEIGHTED counts (the exclusion set E; the tally builds its own). **The divergence, constructed exactly:** one pair at k=2 holding a superseded original + its correction — the census counts both (2); the weighting excludes the original (1). Then: next_pair — 2 ≥ 2 ⇒ ExhaustedQueue raised; tally_rank — leg 3 sees 1 < 2 ⇒ TallyRefusedError raised naming "(a, b) 1 of 2" and the shortfall vote. **The agreement zone:** absent corrections E is empty ⇒ census count == weighted count on every pair — the keyings agree exactly; the divergence exists precisely when unresolved corrections stand in the log — the divergence IS a corrections-present detector. **The divergence as the data-quality signal:** DONE-at-next_pair + SAFE-HALT-at-tally_rank is the observable that a correction has displaced a live judgment below quorum; the caller learns it from the safe halt's own next_action. **Why this IS the design's shape:** each unit honors its own ruled datum — U3's census the audit view (counts as data, never a verdict), U4 owns the weighting alone (the Parnas fold's other half), U5 consults AS-IS by its own gate's letter; consulting U4's weighted view would put U4's keying behind the session's loop — the same leak the no-score fold forbids, and a third counting authority the composition layer is forbidden to own. Reconciliation is not merely declined; it is structurally out of grammar. **The session names the divergence, never reconciles it** — the fixture (§5 edge 3) is the naming.
