## 6. The edge cases the tests must cover

[STATED — G-REGISTRY's conditions, route :96-100.] Concretely [DERIVED]:

1. **The empty list** — refused, found: 0, the refusal text names the count; never an empty ranking, never silence.
2. **The single item** — refused, found: 1 (a distinct found value from the empty list — both under the <2 class, both asserted).
3. **The boundary success** — exactly 2 items, distinct ids: the minimum legal registration mints RUN-0001.
4. **Duplicate ids** — refused naming the duplicate id and its positions; legal set: unique ids.
5. **Malformed operator declaration** — missing/empty id or question; verdict set not the legal form (a foreign set, a non-set, an empty set) — each refused naming the legal form (the triple at birth); the DEFAULT PATH: declaration with no verdict set → the stored manifest carries the triple (the default lands as data).
6. **Quorum-as-data** — omitted → the manifest stores k=1 [STATED — R8]; quorum=2 → stored verbatim (data, not config — the downstream coverage gate keys off the STORED value); quorum=0 / negative / non-integer ("2", 2.5, None) → refused naming the legal form (integer ≥ 1); a large k → accepted [DERIVED — no artificial cap, R6].
7. **The read-back round-trip** — payload in → return out → stored manifest read back equal to the return AND to what was sent (send-vs-stored diffable); re-reading by handle is stable across calls (the freeze); the round-trip is the gate's evidence leg.
8. **The aliasing edge** [DERIVED] — mutate the caller's items list after registration; the stored manifest is unchanged (the copy-in freeze — the test that proves "frozen" means frozen).
9. **The mint sequence** [DERIVED] — three registrations → RUN-0001/0002/0003, monotone; an identical re-registration mints a NEW run (no dedup at the library tier — request idempotency is a service-tier concern); the number never renumbers.

11. **Opacity** [DERIVED] — labels of any content (empty string, unicode, very long) accepted and stored verbatim; the stated question likewise — no content check fires.
