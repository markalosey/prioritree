## 2. KENDALL-TAU OVER GROUPED RANKINGS — the exact form

- The emission: ranked_groups — score-descending tie groups, ids sorted within. The latent truth: a strict total order (zero ties). Over the n₀ = n(n-1)/2 unordered pairs: P concordant, Q discordant, T tied-in-emission (T = Σ|g|(|g|-1)/2); P+Q+T = n₀. **tau = (P-Q)/sqrt((P+Q)·n₀)** (the standard tau-b with the truth untied). Within-group id order is irrelevant to tau — only co-membership and group order matter; the measure reads ranked_groups alone, never scores.
